## 产品简介

OSPTEK **2.95 寸 480×854 TFT** 是一款 **MIPI** 接口彩色显示模组，驱动为 **ST7701S**。

规格标识（仓库名）：`tft-2.95-480x854-mipi-st7701`

当前模组版本：**YDP295B002-V9**。电气与外形细节以 [`docs/YDP295B002-V9.pdf`](./docs/YDP295B002-V9.pdf) 为准。

| 项目 | 规格 |
